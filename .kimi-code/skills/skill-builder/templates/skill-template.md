## 可选 Section 速查

- `## 输出风格`：语态 + 原则 + 典型表达（对话采集型用）
- `## <领域>维度清单`：这个领域要检查/收集什么，分必须/推荐/可选
- `## <领域>策略`：方法论——怎么做
- `## 信息充足度判断`：收集/分析型用，必须满足/尽量满足两档
- `## 压力场景`：触发语句 / 易错行为 / 期望行为，覆盖最危险失败模式
- `## 回退策略`：发布/部署类用
